# Visual Discord Code 0.3.7 검증 — 2026-11-04

- 앱 문법·리소스·버전 및 회귀 검사 107개 통과.
- 출력 통로가 닫힌 상태의 파일 로그, 오류 스택 보존, 파일 오류 전파, 실제 미처리 예외 종료 검사 통과.
- 배포 ASAR의 격리된 Electron 통합 검사 9개 통과. Enter 전송 후 재클릭 없이 다음 초안 입력 포함.
- 최종 Windows ZIP에서 압축 해제한 실행 파일로 버전 0.3.7, 화면 880/1440px, 파일명 전환, 정상 종료 확인. 렌더러 예외 0개.
- Windows ZIP 23개 항목의 CRC, 21개 실행 리소스 해시 및 소스 일치 확인. Electron 실행 파일 원본 바이트 보존.
- Mac Apple Silicon/Intel ZIP 각각 585개 항목 CRC, CPU 종류, 실행 권한과 심볼릭 링크 14개 확인. 두 Mac 배포본의 앱 코드는 Windows와 바이트 단위로 동일.
- 배포 ASAR에는 허용된 앱 소스·리소스와 package.json만 포함. 테스트 코드, 테스트 프로필, 실제 로그인 정보와 대화 데이터는 포함하지 않음.

수정: 전송 확인과 Discord 입력창 비우기가 완료된 뒤 입력 포커스를 복원하도록 보완. 테스트 로그를 파일에 기록하고 자식 테스트의 종료·시간 초과를 추적하여 EPIPE 오류 방지.

실제 Discord 계정에 메시지를 보내지 않았습니다. Mac은 Windows에서 구조·무결성만 검사했으며 실기기 실행, Apple Developer ID 서명·공증은 완료하지 않았습니다. 자동 업데이트와 외부 업로드는 수행하지 않습니다.

# 0.3.6 검증 — 2026-11-04

## 소스 검증 결과

- JavaScript 문법, HTML 참조 파일, 패키지 입력 파일 및 버전 일치: 통과
- 단위·DOM 회귀 검사: 97개 통과
- 별도 렌더러 상태 재생: 480회 통과. 증분 표시와 전체 표시의 HTML, 줄 번호, 첨부 인덱스 일치
- 실제 Electron의 격리된 로컬 시험: 8개 시나리오 통과. 입력·Enter·확인 응답, 새 메시지 한 줄 표시와 재진입, 초안 보호, 파일명 저장·복원, 원래 화면, 최소화·복원, iframe 로딩 중 전송, Ctrl+R 후 초안 보존
- 채널 카테고리 탐색 시험: 200채널·2개 카테고리에서 제목 탐색 10,100회 → 200회. 이름 변경·이동·삭제 반영 확인
- 날짜 형식기 재사용 전후 200메시지 코드 생성: HTML 동일. 순수 코드 생성 중앙값 11.893ms → 5.291ms. DOM·Electron·네트워크와 앱 전체 속도는 측정 범위에서 제외

## 발견 후 수정한 문제

1. 읽기 전용 채널이나 기존 Discord 초안이 있는 경우 이전 대화 불러오기까지 막히던 문제를 수정했습니다. 메시지 전송 제한은 유지합니다.
2. 내부 iframe 로딩이 대화 문서 교체로 오인되어 전송 확인을 취소하던 문제를 수정했습니다. 실제 대화 이동·문서 교체는 계속 전송을 취소합니다.
3. Ctrl/Cmd+R이 코드 화면을 직접 새로고침하여 초안을 잃거나 전송 중 제한을 우회하던 경로를 차단했습니다. Discord 게스트만 새로고침하며 진행 중인 작업은 보호합니다.
4. 미리보기의 내부 글자 이동에 따른 재로딩을 없애고, 닫기·스크롤·계정 초기화 시 이미지 참조를 해제합니다. 가로 스크롤과 확대 제스처는 기록 조회를 시작하지 않습니다.

0.3.4에서 보완한 현재 계정 판별과 과거 동일 메시지의 전송 성공 오인 방지도 회귀 검사에 포함됩니다.

## 배포 및 범위

배포 명령은 소스 검증을 먼저 통과해야 패키징합니다. 최종 Windows 실행 파일 및 Mac ZIP의 버전·구성·무결성 검사 결과는 다운로드 폴더의 검증결과.md와 SHA256SUMS.txt에 기록합니다.

실제 계정으로 메시지를 보내지 않았습니다. Discord 서버 상태와 이후 Discord 화면 구조 변경까지 보장하지는 않습니다. 자동 업데이트 기능은 포함하지 않습니다.

Windows 실행 환경에서 검증했습니다. Mac Command 분기는 단위 검사에 포함했지만 Mac 실기기 실행은 확인하지 못했습니다. macOS 파일은 Apple Developer ID 서명·공증이 없는 시험 배포본입니다.

## 배포 방식 재검증

0.3.5 단일 EXE는 Windows 앱 제어 정책이 내부 실행 파일을 차단하여 이 환경에서 시작하지 못했습니다. 따라서 이전 단일 EXE 실행 검사의 성공 기록만으로 배포 가능 여부를 확정하지 않습니다. 0.3.6은 공식 Electron 실행 파일의 원본 바이트를 유지하는 ZIP 배포를 사용합니다. 실제 배포 파일별 최종 실행·무결성 결과는 해당 다운로드 폴더의 검증결과.md에 기록합니다.

0.3.6 최종 ZIP에서 압축 해제한 Windows 앱은 실제 실행·버전·화면·종료 검사에 통과했습니다. 최종 배포 ASAR 통합 8개 시나리오, 97개 회귀 검사와 480회 렌더러 상태 검사도 통과했습니다. Mac은 구조 검증만 수행했습니다.
