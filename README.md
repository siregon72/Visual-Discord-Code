# Visual Discord Code 0.3.6

VS Code처럼 보이는 독립 앱에서 **실제 Discord 대화를 읽고 보내는** 프로그램입니다. 실제 대화가 왼쪽 탐색기의 `.tsx` 파일로, 메시지가 React·TypeScript 코드의 문자열로 표시됩니다.

VS Code 스타일의 상단 메뉴와 둥근 활동 표시줄, 보랏빛 리본 형태의 전용 아이콘을 사용합니다. 바탕화면의 **Visual Discord Code** 바로가기로 실행할 수 있습니다.

## 실행

`Visual-Discord-Code-0.3.6-Windows-x64.zip`의 압축을 모두 푼 뒤, 폴더 안의 `Visual Discord Code.exe`를 실행하세요. EXE만 따로 꺼내지 말고 같은 폴더의 파일들을 함께 보관하세요. 기존 앱은 종료한 뒤 새 버전을 실행합니다. VS Code 설치는 필요 없습니다. 이전 버전의 로그인은 같은 앱 프로필에 유지됩니다.

로그인이 필요하면 Discord 로그인 화면이 먼저 나타납니다. 로그인 후 자동으로 코드 화면으로 돌아옵니다.

## 실제 채팅

1. 왼쪽 `direct` 폴더에서 `이름.tsx`를 눌러 DM을 엽니다.
2. 서버 폴더를 누르면 해당 서버의 채널을 불러옵니다. 그 안의 `채널.tsx`를 선택하세요.
3. 대화방을 열 때 있던 기록은 React의 상태·변수·함수·JSX 속성 사이에 섞여 표시됩니다. 이후 주고받는 메시지는 입력창 바로 위 `// New messages` 아래에 한 줄씩 표시됩니다. 다른 대화방으로 나갔다 돌아오거나 앱을 다시 열면 새 메시지도 기존 기록처럼 코드에 섞입니다. 받은 메시지는 파란 줄, 본인이 보낸 메시지는 초록 줄로 구분합니다. 코드 줄에 마우스를 올리면 보낸 사람과 시간을 확인할 수 있습니다.
4. 코드 마지막 줄 `setDraft("…");`에 입력하고 **Enter**로 보냅니다. **Shift+Enter**는 줄 바꿈입니다.
5. 전송한 메시지가 Discord 화면에 새로 표시된 것을 확인한 다음 입력 줄을 비웁니다. 실패하거나 확인이 늦으면 초안을 유지합니다. 자동으로 다시 보내지 않습니다.

코드 화면에서는 Discord의 서버 아이콘, 프로필 패널, 큰 이미지와 원래 입력창이 표시되지 않습니다. 샘플 대화는 사용하지 않습니다. 보이는 메시지는 연결된 계정의 실제 대화입니다.

상단 메뉴·검색창·레이아웃 아이콘과 왼쪽 검색·소스 관리·실행·확장·Python·계정·설정 아이콘은 장식용으로 표시되며 클릭할 수 없습니다.

## 보기와 조작

- Explorer 오른쪽 `⋯`: 대화방 이름과 `layout.jsx`, `Header.tsx` 같은 코드 파일명 전환. 열린 탭과 경로도 같은 이름으로 바뀌며, 다시 누르면 원래 이름으로 돌아옵니다. 폴더 접기·펴기는 폴더 옆 화살표를 사용하세요.
- `Ctrl+B` (Mac: `Cmd+B`): 탐색기 접기·펴기
- `Ctrl+Shift+D` (Mac: `Cmd+Shift+D`) / **원래 화면**: Discord 원본 화면 전환
- `F5` / `Ctrl+R` (Mac: `Cmd+R`): 작성 중인 코드 초안을 유지하며 Discord 다시 불러오기
- `Spaces`: 메시지 사이 장식 코드의 양 조절
- 맨 위에서 더 위로 스크롤: Discord에서 이전 대화 불러오기
- `asset("첨부파일명")`에 마우스 올리기: 지원되는 첨부 이미지 미리보기

새 파일 첨부, 통화, 메시지 수정·삭제, 반응 등은 **원래 화면**에서 사용할 수 있습니다. 코드 입력 줄은 텍스트 전송을 지원하며 한 번에 최대 2,000자를 입력할 수 있습니다.

## 동작과 데이터

Discord 웹 화면을 앱 내부에서 실행하고, 현재 렌더링된 대화 목록과 메시지만 읽어 코드 화면에 표시합니다. 코드 화면에서 Enter를 누르면 사용자가 입력한 문장을 Discord의 원래 입력창에 전달하고 전송 키를 누릅니다. 사용자 토큰을 요구·추출하거나 비공식 메시지 API를 호출하지 않습니다.

대화 목록과 코드 화면의 미전송 초안은 실행 중 메모리에만 보관됩니다. 앱을 닫으면 코드 화면 초안이 사라집니다. Discord 로그인 쿠키와 웹 캐시는 앱 전용 프로필에 보관됩니다. **로그아웃**은 확인 후 이 앱의 로그인 정보를 지우며 계정이나 메시지를 삭제하지 않습니다.

코드 파일명 표시 설정과 대화 주소별 파일명 대응은 앱 프로필에 저장해 다음 실행에도 유지합니다. 이 설정에는 실제 대화방 이름이나 메시지 내용을 저장하지 않습니다. 표시 이름을 바꿔도 실제 Discord 대화방과 전송 대상은 바뀌지 않습니다.

전송 중에는 대화 전환을 막으며, 전송 직전 대화 주소와 원래 입력창 상태를 다시 확인합니다. 원래 화면에 작성 중인 초안이 있으면 덮어쓰지 않습니다. 결과가 불확실하면 **원래 화면에서 전송 여부를 확인**한 뒤 입력을 다시 사용하세요.

Discord가 화면 구조를 바꾸면 목록이나 메시지 읽기를 조정해야 할 수 있습니다. 메시지 목록은 Discord가 현재 로드한 범위이며 전체 과거 내역을 한꺼번에 다운로드하지 않습니다. 장식용 React·TypeScript 코드는 실행되지 않습니다.

## 개발과 검사

0.3.5에서는 읽기 전용 채널의 이전 대화 불러오기와 미리보기 처리를 보완하고, 채널 카테고리 탐색·시간 표시·파일명 배정의 반복 작업을 줄였습니다.

0.3.3에서는 새 메시지만 화면 끝에 추가하고, 한 번의 Discord 화면 조회 안에서 중복 작업을 줄였습니다. 창을 최소화하면 주기 조회를 쉬고 복원하면 바로 갱신합니다. Windows 패키지에는 한국어·영어 엔진 리소스를 포함합니다. Discord 웹의 메시지와 언어 설정은 그대로 사용할 수 있습니다. 측정 범위와 결과는 `docs/PERFORMANCE.md`에 있습니다.

Node.js 24 이상에서:

```powershell
npm ci
npm start
npm run validate
npm run test:desktop
npm run dist
```

`npm run validate`는 JavaScript 문법·필수 리소스·패키지 구성을 확인하고 회귀 검사를 실행합니다. 배포 명령도 이 검사를 먼저 통과해야 패키징합니다. 화면 배치와 기존 수동 전송 방식은 유지합니다.

Electron 엔진이 없다면 `node node_modules/electron/install.js`를 실행하세요. 빌드 결과는 `dist/`에 저장됩니다.

`test:desktop`은 모든 게스트 HTTPS 요청을 시험용 화면으로 가로채고 실제 입력·Enter·메시지 반영을 검사합니다. 이 검사는 실제 Discord 계정이나 사람에게 메시지를 보내지 않습니다.

- `main.js`: Electron 시작·종료와 창 생성
- `src/main/`: Discord 연결 수명, 작업 순서, IPC와 권한 처리
- `src/shared/contracts.js`: 허용 요청 및 스냅샷 형식 검증
- `discord-adapter.js`: 공개된 Discord 화면의 대화·메시지·입력창 읽기
- `send-message.js`: 수동 전송, 중단 조건, 본인 메시지의 전송 결과 확인
- `live.js`: 화면 이벤트와 실제 입력 동작 연결
- `src/renderer/`: 상태·초안, 탐색기, React 코드 표현, 안전한 텍스트 처리
- `live.html`, `styles.css`: 화면 구조와 통합 스타일
- `tests/`: 경로, 상태 전환, DOM, 한글 입력, 초안과 전송 회귀 검사
- `docs/ARCHITECTURE.md`: 구조와 유지보수 기준

비공식 개인용 프로젝트이며 Discord 및 Microsoft와 제휴하지 않습니다. Windows 실행 파일은 코드 서명되어 있지 않습니다.

## 0.3.6 Windows 배포

재검증에서 리소스를 편집한 단일 EXE가 현재 Windows 앱 제어 정책에 차단되는 것을 확인했습니다. 공식 Electron 실행 파일의 원본 바이트를 유지하는 ZIP 배포로 변경했습니다. 보안 정책은 변경하지 않습니다. 앱 창과 바탕화면 바로가기는 전용 아이콘을 계속 사용하지만, 폴더 안 EXE 자체의 파일 아이콘·메타데이터는 Electron 원본을 유지합니다. 다른 PC의 보안 정책까지 보장하지는 않습니다. 자동 업데이트는 포함하지 않습니다.
