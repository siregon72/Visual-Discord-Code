# Visual Discord Code

VS Code처럼 보이는 Discord 앱입니다. 왼쪽 탐색기에서 대화를 파일처럼 열고, React·TypeScript 코드 사이에서 메시지를 읽고 보낼 수 있습니다. VS Code를 따로 설치할 필요는 없습니다.

## 1. 설치하고 실행하기

현재 버전은 **0.3.7**입니다. 내 컴퓨터에 맞는 ZIP의 압축을 모두 풀어 주세요.

- **Windows 64비트:** `Visual-Discord-Code-0.3.7-Windows-x64.zip`을 풀고, 폴더 안의 `Visual Discord Code.exe`를 실행합니다. EXE와 함께 들어 있는 파일을 같은 폴더에 두세요.
- **Mac · Apple Silicon:** `Visual-Discord-Code-0.3.7-macOS-AppleSilicon.zip`을 풀고, 안의 앱을 실행합니다.
- **Mac · Intel:** `Visual-Discord-Code-0.3.7-macOS-Intel.zip`을 풀고, 안의 앱을 실행합니다.

Mac 버전은 macOS 13 이상을 대상으로 하는 시험 배포본입니다. Mac 실기기 실행 검증과 Apple 서명·공증은 아직 완료하지 않았습니다.

새 버전으로 바꿀 때는 실행 중인 앱을 먼저 종료하세요. 자동 업데이트 기능은 없으며, 같은 컴퓨터에서는 기존 로그인 정보가 유지됩니다.

## 2. 로그인하기

처음 실행하면 Discord 로그인 화면이 나타납니다. 화면이 보이지 않으면 오른쪽 위 **로그인**을 누르세요.

앱 안의 `discord.com` 페이지에서 로그인하면 자동으로 코드 화면으로 돌아옵니다. 다음부터는 로그인된 상태로 열립니다.

## 3. 대화 열기

- 왼쪽 **Explorer**의 `direct` 폴더 안에서 `이름.tsx`를 누르면 DM이 열립니다.
- 서버 폴더를 누르면 해당 서버의 채널을 불러옵니다. 그 안의 `채널.tsx`를 눌러 대화를 여세요.
- 폴더 옆 화살표로 목록을 접고 펼 수 있습니다.
- 탐색기의 `README.md`를 누르면 앱 안의 간단한 사용 안내를 다시 볼 수 있습니다.

목록이 비어 있으면 `direct` 또는 서버 폴더 이름을 눌러 대화를 불러오세요.

## 4. 메시지 읽기

대화를 열면 기존 메시지가 변수, 함수, JSX 속성 안의 문자열로 표시됩니다.

```tsx
const label_demo = "안녕!";
const item_test: ViewItem = {
  label: "지금 뭐 하고 있어?", enabled,
};
```

- **파란 막대:** 상대가 보낸 메시지
- **초록 막대:** 내가 보낸 메시지
- **보낸 사람·시간:** 메시지가 들어 있는 코드 줄에 마우스를 올려 확인
- **사진·GIF:** `asset("photo.jpg")` 같은 표시에 마우스를 올리면 지원되는 이미지의 미리보기 표시
- **이전 대화:** 코드 화면 맨 위에서 더 위로 스크롤하여 불러오기

대화를 열어 둔 동안 새로 주고받는 메시지는 맨 아래 `// New messages` 아래에 한 줄씩 이어집니다.

```tsx
// New messages
setValue("안녕!");        // 받은 메시지
setDraft("반가워!");      // 내가 보낸 메시지
```

다른 대화방에 갔다 돌아오거나 앱을 다시 열면 새 메시지도 기존 기록처럼 코드에 섞여 보입니다. 메시지 사이의 장식 코드는 실행되지 않습니다.

## 5. 메시지 보내기

1. 대화 맨 아래의 `setDraft("…");` 입력 줄을 누릅니다.
2. 보낼 내용을 씁니다. 따옴표와 괄호는 화면에 이미 있으므로 내용만 입력하세요.
3. **Enter** 또는 입력 줄 오른쪽의 **↵**를 눌러 보냅니다.

**Shift+Enter**는 줄 바꿈입니다. 한 번에 최대 **2,000자**를 보낼 수 있습니다.

전송이 확인되면 입력 줄이 비워집니다. 확인이 늦거나 실패하면 작성한 내용이 남아 있으므로, **원래 화면**에서 전송 여부를 먼저 확인하세요.

## 6. 사진·파일·통화 사용하기

오른쪽 위 **원래 화면**을 누르면 실제 Discord 화면으로 전환됩니다. 여기서 사진·파일 첨부, 통화, 메시지 수정·삭제, 반응 등을 사용할 수 있습니다.

다시 **코드 화면**을 누르면 코드 형태의 대화로 돌아옵니다. 코드 화면의 입력 줄은 텍스트 전송을 지원합니다.

## 7. 대화 이름을 코드 파일명으로 바꾸기

Explorer 오른쪽의 **⋯**를 누르면 대화방 이름이 `layout.jsx`, `Header.tsx` 같은 코드 파일명으로 바뀝니다. 다시 누르면 원래 대화 이름으로 돌아옵니다.

탐색기, 열린 탭, 상단 경로에 같은 이름이 표시됩니다. 표시 이름만 바뀌며 실제 대화 상대와 채널은 그대로입니다. 이 설정은 다음 실행에도 유지됩니다.

## 8. 장식 코드 양 조절하기

아래 상태 줄의 **Spaces: 2**를 누를 때마다 `2 → 4 → 8 → 0 → 2` 순서로 바뀝니다.

숫자가 클수록 메시지 사이에 장식 코드가 많이 들어갑니다. `0`에서는 메시지를 담은 변수 선언과 기본 컴포넌트 구조 위주로 표시됩니다.

## 그 밖의 조작

| 기능 | Windows | Mac |
| --- | --- | --- |
| 메시지 보내기 | Enter | Enter |
| 입력 중 줄 바꿈 | Shift+Enter | Shift+Enter |
| 탐색기 접기·펴기 | Ctrl+B | Cmd+B |
| 원래 Discord 화면 전환 | Ctrl+Shift+D | Cmd+Shift+D |
| Discord 새로고침 | F5 또는 Ctrl+R | Cmd+R |

- 왼쪽 맨 위 **탐색기 아이콘**으로도 사이드바를 접고 펼 수 있습니다.
- 탭 줄 오른쪽의 **↻**는 새로고침, **↵**는 코드 화면의 긴 줄을 줄 바꿈해서 보여 주는 버튼입니다.
- 열린 탭의 **×**를 누르면 앱 안의 사용 안내로 돌아갑니다.
- 상단 메뉴·검색창·레이아웃 아이콘과 탐색기 이외의 왼쪽 활동 아이콘은 장식용입니다.

## 문제가 생겼을 때

- **대화가 갱신되지 않아요:** 탭 줄의 **↻** 또는 새로고침 단축키를 눌러 주세요.
- **입력 줄이 없어요:** `README.md` 대신 대화 파일을 열었는지, 해당 채널에 메시지를 보낼 권한이 있는지 확인하세요.
- **원래 Discord 입력창에 작성 중인 내용이 있다고 나와요:** **원래 화면**에서 그 초안을 먼저 확인하고 정리하세요.
- **전송 결과를 확인하지 못했다고 나와요:** **원래 화면**에서 메시지가 보내졌는지 확인한 뒤 **확인 후 입력 다시 사용**을 누르세요. 앱은 자동으로 재전송하지 않습니다.

Discord가 화면 구조를 변경하면 대화 목록이나 메시지 표시가 일시적으로 동작하지 않을 수 있습니다. 이때는 **원래 화면**에서 대화를 이어가세요.

## 로그아웃과 초안

왼쪽 아래 **연결 계정 로그아웃**을 누르고 확인하면 이 앱에 저장된 Discord 로그인 정보와 웹 캐시를 지웁니다. Discord 계정과 대화는 삭제되지 않습니다.

코드 화면의 미전송 초안은 앱이 켜져 있는 동안 대화별로 유지되며, 앱을 종료하면 사라집니다.

## 개발

<details>
<summary>소스에서 실행·검사·빌드하기</summary>

Node.js 24 이상에서 실행합니다.

```powershell
npm ci
npm start
```

- `npm test`: 단위·DOM 회귀 검사
- `npm run validate`: JavaScript 문법·필수 리소스·패키지 구성 및 회귀 검사
- `npm run test:desktop`: 별도 테스트 프로필에서 실제 Electron 입력·전송 동작 검사
- `npm run dist`: 검사를 통과한 뒤 Windows x64 ZIP 생성 (`dist/`)

Electron 엔진이 없다면 `node node_modules/electron/install.js`를 실행하세요.

데스크톱 검사는 시험용 화면에서 실행되며 실제 Discord 계정이나 사람에게 메시지를 보내지 않습니다. 실행기는 검사 종료를 기다리고, 매번 별도의 `test-results/live-desktop/run-…/` 폴더에 `test.log`, `stdout.log`, `stderr.log`, `launcher.log`를 남깁니다. 60초 안에 끝나지 않으면 자신이 시작한 테스트를 종료합니다. `VDC_TEST_OUTPUT`으로 결과 경로를, `ELECTRON_EXEC_PATH`로 Electron 실행 파일을 지정할 수 있습니다.
